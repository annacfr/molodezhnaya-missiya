# Миссия: молодёжная команда

Игровая мобильная памятка по индивидуальному заданию №1. Откройте `index.html` или используйте опубликованную версию GitHub Pages.

Сайт сделан как одна адаптивная HTML-страница. Перетаскивание карточек работает касанием через Pointer Events; тема и чек-лист сохраняются в браузере.
